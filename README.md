## <a name="english"></a> 🇬🇧 English

### Project Name

Endang Stock Management System (Frontend)

### Description

Endang Stock Management System is a comprehensive web-based frontend application designed to help businesses manage their inventory efficiently. It provides an intuitive dashboard and tools to track products, manage categories, brands, and units, monitor stock movements (in, out, and mutations), and generate detailed reports. The application also includes user and role management features for secure access control.

### Tech Stack

- **Framework**: Vue.js 3 (Composition API)
- **Routing**: Vue Router
- **Styling**: Tailwind CSS v4
- **UI Components**: PrimeVue 4
- **Build Tool**: Vite
- **Language**: TypeScript
- **HTTP Client**: Axios
- **Real-time Communication**: Socket.io-client
- **PDF Generation**: jsPDF & jsPDF-AutoTable
- **Charts**: Chart.js
- **Animations**: LottieFiles (dotlottie-vue)
- **Testing**: Cypress (E2E)

### Features

- **Authentication**: Secure login system with permission-based access.
- **Dashboard**: Overview of stock metrics and activities.
- **Product Management**:
  - Manage Product Data (Add, Edit, View)
  - Manage Product Categories
  - Manage Product Brands
  - Manage Product Units
- **Inventory & Stock Management**:
  - **Product In**: Record and manage incoming stock.
  - **Product Out**: Record and manage outgoing stock.
  - **Product Mutation**: Track stock transfers between locations.
- **Store & Warehouse Management**:
  - Store Stock monitoring.
  - Warehouse Stock monitoring.
- **Reports**:
  - Generate comprehensive reports for incoming products, outgoing products, and stock mutations.
- **Settings & Authorization**:
  - **User Management**: Add, edit, and view user details.
  - **Role Management**: Configure user roles and permissions.

## <a name="indonesia"></a> 🇮🇩 Bahasa Indonesia

### Nama Proyek

Sistem Manajemen Stok Endang (Frontend)

### Deskripsi

Sistem Manajemen Stok Endang adalah aplikasi frontend berbasis web komprehensif yang dirancang untuk membantu bisnis mengelola inventaris mereka secara efisien. Aplikasi ini menyediakan dasbor intuitif dan alat untuk melacak produk, mengelola kategori, merek, dan satuan, memantau pergerakan stok (masuk, keluar, dan mutasi), serta menghasilkan laporan terperinci. Aplikasi ini juga dilengkapi dengan fitur manajemen pengguna dan peran untuk kontrol akses yang aman.

### Tech Stack (Teknologi yang Digunakan)

- **Framework**: Vue.js 3 (Composition API)
- **Routing**: Vue Router
- **Styling**: Tailwind CSS v4
- **UI Components**: PrimeVue 4
- **Build Tool**: Vite
- **Bahasa Pemrograman**: TypeScript
- **HTTP Client**: Axios
- **Komunikasi Real-time**: Socket.io-client
- **Pembuatan PDF**: jsPDF & jsPDF-AutoTable
- **Grafik/Chart**: Chart.js
- **Animasi**: LottieFiles (dotlottie-vue)
- **Pengujian (Testing)**: Cypress (E2E)

### Fitur

- **Autentikasi**: Sistem login yang aman dengan akses berbasis hak akses (permissions).
- **Dasbor (Dashboard)**: Ringkasan metrik dan aktivitas stok.
- **Manajemen Produk**:
  - Kelola Data Produk (Tambah, Edit, Lihat)
  - Kelola Kategori Produk
  - Kelola Merek Produk
  - Kelola Satuan Produk
- **Manajemen Inventaris & Stok**:
  - **Barang Masuk (Product In)**: Mencatat dan mengelola stok yang masuk.
  - **Barang Keluar (Product Out)**: Mencatat dan mengelola stok yang keluar.
  - **Mutasi Barang (Product Mutation)**: Melacak perpindahan stok antar lokasi.
- **Manajemen Toko & Gudang**:
  - Pemantauan Stok Toko (Store Stock).
  - Pemantauan Stok Gudang (Warehouse Stock).
- **Laporan**:
  - Menghasilkan laporan terperinci untuk barang masuk, barang keluar, dan mutasi barang.
- **Pengaturan & Otorisasi**:
  - **Manajemen Pengguna (Users)**: Tambah, edit, dan lihat detail pengguna.
  - **Manajemen Peran (Role)**: Mengonfigurasi peran dan hak akses pengguna.
